## How it works

1. Browse the public shelf. Filter by aisle.
2. Live Stripe links take the card.
3. Sign in and list on the first live market. Newest listing takes the front row. Optional Connect `acct_` — FORGE keeps 10%.
4. Crypto tape is live prices. Card takes the money.
