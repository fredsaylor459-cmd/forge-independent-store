# FORGE

Independent crypto marketplace storefront.

## Live
- Vercel: https://forge-independent-store-fredsaylor459-8579s-projects.vercel.app
- If Vercel asks you to log in, open Deployment Protection in the project and turn Vercel Authentication off so the public can enter.

## What works now
- Live market clock
- Product grid + filters
- List a build (front-row rotation, saved locally)
- Cart
- Connect MetaMask if present, otherwise demo wallet
- Checkout writes a SHA-256 receipt hash

This is a working storefront. Real on-chain transfer still needs a payment address + signed transaction next.
